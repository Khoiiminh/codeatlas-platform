# packages/contracts

**Layer:** Adapter support (generated)

Generated TypeScript types for the engine's canonical contracts (`@codeatlas/contracts`), pinned to an engine contract release. **No schema forks.**

**May depend on:** nothing.

**Must not depend on:** being imported by `packages/domain` or `packages/application`

**Contains:**
- Generated types with their source contract version
- Reproducible generation script

See [ADR-0011](../../docs/adr/0011-platform-clean-architecture-bounded-contexts.md) and the [dependency matrix](../../docs/architecture/README.md).
